Vanilla.ts Sample Apps

There are currently two Vanilla.ts sample apps, a simple example app and a showcase app. The example app is a simple app that demonstrates a very basic usage of some Vanilla.ts components. The showcase app is more comprehensive, it contains examples and sample usage of all components from all Vanilla.ts projects (Vanilla.ts Core, Vanilla.ts DOM and Vanilla.ts Components).
